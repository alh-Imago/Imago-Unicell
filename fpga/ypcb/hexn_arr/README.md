# hexn_arr: one hex pattern array on the Kintex (YPCB-00338-1P1)

Purpose: real placed size and clock of the small arrays (7x7, 6x6, 5x5), one pattern per build. This is step 1 of the "judge and arrays on one Kintex" plan (selector and program library, then judge after / before / during).

Design: `hexn_arr.v` (static board top: JTAG bridge on USER2, IR 0x03, plus the array core), `hexn_arr_core` and the pattern RTL (generated by `prebuild.py` from a reference JSON through `tools/hexn_kxarr_v1.py`), `hexn.xdc` (SYS_CLK AA28, LEDs P30/M30/N30, LVCMOS18). Frame v4 = the Tang frame with a byte port; ticks are identical (checked in simulation).

## Build (does not touch the board)
    git -C ~/hexn-wt pull origin Hex-N
    cd ~/ypcb-00338-1p1   # openXC7 nix shell, no sudo
    ln -sfn ~/hexn-wt/fpga/ypcb/hexn_arr designs/hexn_arr
    bash ~/hexn-wt/fpga/ypcb/hexn_arr/run_arr.sh hex7_off2_mix      # then: hex6, hex5
Report back the SUMMARY block (utilisation, Max frequency) and the build time.
