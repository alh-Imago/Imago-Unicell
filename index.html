Topology is computation.

Imago UniCell is a spatial FPGA compute architecture. There's no CPU, no instruction set, and no shared bus — a physical cell holds a fixed set of real hardware cores, each wired directly to its North/South/East/West neighbors. Computation happens as values arrive and propagate across that topology, one wire-delay hop at a time. No global clock coordinates it — wire delay does.

What this actually is, stated plainly: a research project building real, working pieces of this architecture, on real hardware, with real measured numbers. It is not a general-purpose computer, and not something you can install today. If the PCIe host-integration work succeeds, the realistic best case is an FPGA accelerator card for specific spatial-dataflow workloads — not a CPU replacement.

STATUS THE SUPER CARRIER SHELL

Real, Quartus-confirmed silicon numbers

The active architecture is the super carrier shell: a single physical FPGA cell holding six real, different cores simultaneously — a NOR-gate logic cell, RAM, an adder, an accumulator, a comparator, and a latch — with the active one chosen by a runtime configuration write, not a synthesis-time choice.

CONFIRMED

Total shell cost

213 ALM, 257 registers — all 6 cores physically present in every bitstream.

CONFIRMED

Isolation/selection overhead

25.9 ALM — smaller than any one of the 3 largest individual cores.

CONFIRMED

Timing

clk_div 200.76 MHz — 8.03× margin over the 25 MHz requirement, the best margin of any build so far.

TESTED

Software stack

A real VM, ICM v3 program format, tile library, DSL compiler with two independent frontends, and a working browser workbench — all genuinely tested in simulation, not yet independently confirmed on hardware as these specific multi-cell layouts.
