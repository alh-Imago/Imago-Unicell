## fpga_bringup.py — Six-step bring-up sequence

### Design

Self-contained script. CLI flags:

    python fpga_bringup.py --sim                     # VM, no hardware
    python fpga_bringup.py --port /dev/ttyUSB0       # iCEBreaker
    python fpga_bringup.py --sim --step 3            # single step
    python fpga_bringup.py --sim --verbose           # per-tick trace

When the iCEBreaker arrives: change --sim to --port. Nothing else changes.

### Steps

| Step | Name | What it tests | Pass condition |
|:-----|:-----|:--------------|:---------------|
| 1 | RESET | Array resets, status responds | armed=0 after reset |
| 2 | UART | PASS cell round-trip 0xDEADBEEF | data echoed back correctly |
| 3 | NOT gate | Single cell, LOOP_MODE, truth table | NOT(0)=1, NOT(1)=0 |
| 4 | AND gate | SYNC_WAIT two-input, truth table | AND 4/4 correct |
| 5 | RELAY pair | NOT→NOT chain, isolation | NOT(NOT(1))=1, isolation confirmed |
| 6 | SCALE | 8 cells simultaneous, 16 truth checks | 16/16 correct |

### Failure hints

Each step prints a targeted hint on failure, pointing at the hardware
component or code path most likely responsible.

### Bugs found during development

Three real issues surfaced writing this script — all now fixed and documented:

**Bug 1: FUNCTION_LOAD_PATTERN as inject data**
MAGIC = 0xA5A5A5A5 (used for UART echo test) is the same value as
FUNCTION_LOAD_PATTERN. Injecting it as data triggers the cell's config
state machine and silently reconfigures the cell. Fixed: MAGIC = 0xDEADBEEF.

**Bug 2: NOT cell disarms after single fire without LOOP_MODE**
The truth table needs two injections (NOT(0), NOT(1)). Without LOOP_MODE,
the cell fires once and disarms — the second injection produces no output.
Fixed: all bring-up test cells use LOOP_MODE.

**Bug 3: LOOP_MODE cells re-fire on stale bus in scale test**
With 8 LOOP_MODE NOT cells sharing the bus, injecting into cell N leaves
its input address on the bus. Other cells' LOOP_MODE re-fires see the stale
value and emit spurious outputs, filling the pending queue before cell N+1's
result arrives. Fixed: clear bus and pending queue before each cell's inject.
