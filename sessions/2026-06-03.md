## Part 1 — VoxCell photonic architecture (design exploration)

Started from an offhand thought about photonics as a UniCell substrate.
Worked through to a serious and documented architectural direction.

### Key technical derivations

**Two-wavelength two-arrival mapping**
- λ₁ (1310nm) = command channel, arms cell
- λ₂ (1550nm) = data channel, triggers execution
- Maps directly onto existing two-arrival model — physics does the work

**Voxel routing**
- Different wavelengths / orthogonal polarisations cross without crosstalk
- 3D lattice with free path crossing — eliminates the primary routing
  constraint that dominates silicon layout
- 6 faces per voxel, 12 independent channels at each intersection point

**PCM optical storage**
- GST (Ge₂Sb₂Te₅) on-waveguide — non-volatile, re-writable ~10⁶ cycles
- Maps directly onto `a_data` — the cell's natural holding behaviour
- Write via induction-gated laser pulse (authenticated reset pattern)
- Slow write maps onto existing load(A)/run(B) separation — by design

**Crystallised computation**
- Stored topology IS the executable
- Query injection IS execution
- Pattern-addressable associative retrieval — mnemonic memory circuit
  in the precise sense of the word
- Applications: HSM, ECU, neural inference, genomic lookup

**Manufacturing path**
- 130nm SOI — mature process, depreciated tooling at any sub-28nm fab
- MPW shuttle: AIM Photonics, Europractice, LIGENTEC
- Demo tile cost estimate: £2,000–8,000 for 3×3mm–5×5mm tile
- Post-fab GST deposition: standard sputtering, university thin-film lab
- Total demo cost: under £15,000, possibly well under with academic access
- UK contacts: Southampton ORC, UCL, Bristol, Heriot-Watt

**Honest open questions (need numbers before MPW)**
- SOA NOR gate power budget per cell
- PCM write/read endurance at waveguide scale
- Voxel addressing scheme
- MPW tile size vs cell count tradeoff
- WDM splitter insertion loss budget across lattice depth

### Trek connection
The prop designers called it a mnemonic memory circuit in 1967.
Mnemonic = pattern-addressable associative retrieval.
That is precisely what the photonic voxel lattice does.
The word was chosen for dramatic effect. It was accidentally correct.

### INT32_MUL tile
**Commit: 8a02b23**

32-bit multiply, low 32 bits, correct for signed and unsigned.
Shift-and-add over 32 partial products, ripple carry accumulator.

Key fix during development: driven-zero cells (NOT/NOT pairs) stall in
the two-arrival model — they have a_arrived=True from preload but their
input address never gets a second arrival. Fix: skip adder cells
entirely for zero partial product bits (pp_idx out of range), passing
accumulator bit through unchanged. Cell count dropped from 6387 to 2915.

Also fixed: INT32_MUL added to one_shot exemption list in test_fp_tiles.py
(carry propagation needs multi-cycle execution, same as ADD/SUB).
