**#1029 -- THE WIDE fp64 MULTIPLIER (Alan: "start with the wide version first"): the 53x53 = 106-bit product through a 64-bit word, BIT-EXACT in the generated RTL in all five rounding modes, with inf / nan / overflow / subnormals (5 new tests; the 12 narrow multiplier tests still pass).** fp64 tight U multiplier 2,208 cells (rne; 2,170 rtz, 2,370 rup / rdn with the sign lane into the rounder), 48x192 squares.
