  • README.md Start here — what the project is, where things stand (the Arria 10 and Tang Nano 20K lines), and a quick start.

  • docs/playout_capture_v1.md The unit's register map, SPI protocol, breadboard wiring sheet and measured results.
  • tools/README.md The assembler (program file → Verilog) and the measurement tools.
  • docs/stripped-cell/CELL_GOTCHAS.md Behaviours that will silently bite you, each one found the hard way.
  • docs/stripped-cell/UNICELL_S_DSL_MANUAL.md The DSL language reference — every example compiled and confirmed working.
  • docs/stripped-cell/SUPER_CELL_INTERNALS.md The Arria 10 line's super carrier shell: field maps, mechanisms, real silicon numbers.

  • nano/ The VM (including the flex mirror), program formats, tile libraries, compilers and frontends, and the workbench.
  • sub/ The sub and flex cell RTL, each cell with its own self-checking bench.
  • archeology/onion/ Earlier project work, preserved byte for byte and checksum-verified, not deleted.
FIG. 13 TOOLCHAIN

Open Gowin flow (current)

yosys synth_gowin, nextpnr-himbaechel-gowin, Apicula gowin_pack and openFPGALoader — synthesis to a flashed Tang Nano 20K with no vendor tools.

Icarus Verilog

iverilog -g2012 / vvp for RTL simulation — sim-first, then silicon, throughout. The generated designs are checked against the VM this way.

Python

The nano/ stack — VM, compilers, DSL, workbench. The LLVM IR frontends need llvmlite; the test suites need pytest.

Quartus Prime 25.1 (Arria 10 line)

Standard Edition on Windows, the path for the earlier Arria 10 card (IEI Mustang-F100-A10). The licence has since expired.
