Simulation limitations
This sim models individual cells only — not tile networks.

SYNC_WAIT (B-input gating) is not modelled. Cells with a B address evaluate immediately with B=0 if no value has been injected to that address.

Tile pipeline depth is not tracked. A placed tile (INT32_ADD, LIF neuron, etc.) spans hundreds of cells across many ticks; the sim shows each cell firing once independently, not the full pipeline.

LOOP_MODE cells re-arm each tick as expected.

For tile-based designs, use the Python VM: imago run my_design.icm
