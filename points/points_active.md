**RTL:** `sc_sys_v23.v` (v22 stays), parameter MULU (0 = nothing added, the window traps as in v22). With 1: a device window at data word index 2^(SHL+1) (byte 0x20000): store +0 = operand A, store +4 = operand B, load +8 = (A*B) mod 2^32; anything else in it traps (cause code 2; no new cause code). Per slice: operand registers, written straight from the finished store word (no slot wait); a product load is a shared-RAM-style read request flagged `rq_dev`, held 3 clocks after the last device store (`dv_stale`). Per block: one multiplier fed the operands of the slice whose slot comes 2 clocks later (`msel`), three register stages, so `mul_q` holds that slice's product when it captures (replaces `sdq` for a flagged read). The multiply is a plain 32x32 low-32 `*`: yosys maps it to 3 DSP48E1 (checked alone, 3). Whole-top synthesis in yosys (2 blocks, S=8): 7 DSP48E1 with MULU=1, 1 with MULU=0, i.e. +3 per block; the 1 that every Kintex build has is still unexplained (it is there with MULU=0 too). Resource numbers beyond DSP count were not looked at.
**Tests (iverilog, test_sys23.py + tb_sys23.v):** S=8 ULW 2 NU 2, S=4 ULW 2 NU 1, S=16 ULW 3 NU 2: 16 products (edge cases and random) correct at every fusion width alone and together, mixed with ordinary jobs and with the bad accesses (load from +0, store to +8, word +12), which trap with cause 2; the real library routine `jobio/lib_mul_unit.s` called with a jump gives the right products; with MULU=0 all multiply programs trap (cause 2) and the ordinary programs (sum100, fib, crc32, softmul_gcd) still pass. **Host side:** `jobio/lib_mul.s` (software shift and add, #1582) and `jobio/lib_mul_unit.s` (unit); `jobio_ext_v1.py` links the unit version when the build's `mul_units` > 0 and the software version otherwise, writes the count into job header word 7, and installs `jobiss_v2.py` (the interpreter with a model of the unit). **Change from the plan in #1580/#1581:** the choice is made at link time from the build's `mul_units`, not by a run-time test of word 7 (that test would have cost one shared-RAM access per multiply: 207 clocks at lw 0, 32 at lw 5); the header word is still written, for information.
