Verilog is the language the hardware is written in. Everything on earlier pages ran in the VM, a Python model of the cells. This page is about the other form of the same design: a small text file per kind of cell, which a chip tool turns into real wiring inside an FPGA (a chip you can rewire). It also shows where the design keeps what the program does apart from which card it runs on.

What is in the Verilog folder

Everything lives in sub/verilog/. Each kind of cell is one short file, and each has a matching test file (a "testbench") that feeds it numbers and checks what comes out. The counts below are read from the folder when this page was built.

Two families exist side by side. The stripped family (v4s) has no way for a cell to say "wait": every cell takes a fixed number of clock ticks, so the builder must pad early paths with spare relay cells so values meet on the same tick. The flex family (v4sa) adds a "ready / taken" handshake and a word width you choose, so cells wait for each other and nothing needs padding. Pick a family to see the cells it has and the real ports of its adder.

Where the design keeps the logic apart from the card

A program is written once, as a map of cells (an ICM file). It says nothing about any card: no pins, no chip sizes, no clock. What the card offers is held in a second file, the MAN file (the next page). A tool called the assembler reads both and writes the Verilog and the build script for that pairing. Change the card file and the same program is built differently; change the program and the same card is used differently.

What this shows, and what it does not

Scope. Every column above is the real output of tools/project_assemble_v1.py, captured by docs/teaching/capture_rtl_v1.py against the files in the repository; file lines, flags, widths and messages are read from the run, not typed. The generated Verilog was not simulated or synthesised for this page: no Verilog simulator is installed here, and the synthesis tools were not run. The cell libraries and their testbenches are counted, not re-run. The Mustang card is the older line; its MAN file was assembled by hand, the Tang Nano one by a script.
