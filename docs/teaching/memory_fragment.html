Everything so far forgot its value as soon as it passed it on. Two small cells keep something. The latch remembers a single bit until it is told to change; the sequencer remembers a short list and steps through it one value at a time.

1. The latch: one bit that stays

A latch has three one-bit event inputs: set (make it 1), clear (make it 0) and toggle (flip it). Nothing else changes it. If events arrive together the order is fixed: clear beats set, and set beats toggle. After each event the cell reports its new value on its output and holds that report until the receiver takes it.

Try pressing events one at a time. Then try switching the receiver to stuck and pressing more: the stored bit keeps changing, but the cell cannot report it, because the last report has not been taken.

2. The sequencer: a short list, one step at a time

A sequencer is configured with up to four 8-bit values (0 to 255) and a length. It starts standing on the first value. Each advance pulse moves it on to the next value and offers that one; after the last it goes back to the start. The values come out in a fixed order, from nothing but a counter: no program, no addresses. One more rule: an advance that arrives while the last value is still waiting to be taken is ignored.

3. What to notice

  • Memory is just a value that is not thrown away. The latch keeps its bit through any number of ticks in which nothing happens. Every other cell on the earlier pages passed its value on and let go.
  • Remembering and reporting are separate. The latch updates its bit on every event, but it can only tell the next cell when its last report has been taken. Under pressure the memory is right and the report is late.
  • A fixed order needs no program. The sequencer's whole behaviour is a counter that wraps and four stored values. That is how a repeating pattern, such as the steps of a motor or a lamp, can come from a cell and not from instructions.
  • The first advance does not repeat the starting value. The cell starts standing on value 0 and the first advance steps on to value 1, which is the first one offered. Value 0 comes out last in the first lap.
