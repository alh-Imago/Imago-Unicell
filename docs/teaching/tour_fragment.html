Everything on this page is a picture of something that is already in the repository. The boxes and file names are links, so you can jump straight to the part you want. Nothing on this page needs a circuit board.

1. What is where

The route a learner takes: draw a small circuit, run it a step at a time, look inside one cell, and (only if you want to) see the same idea on a real board. The highlight moves along the route to show the order.

1 · DRAW

The composer

Place cells on a board, say what each one does, and join them with wires.

nano/composer_page_v1.py

Open it with python3 quickstart.py --composer

2 · RUN

The step simulator

Put values in, then advance one tick at a time and watch every value move. It runs on the VM (a Python model of the cells).

tools/flex_layout_sim_v1.py
nano/flex_grid_v1.py

3 · LOOK INSIDE

One cell

The nano cell is ten NOR gates and a selector. Try it live in section 2 below.

sub/verilog/nano_cell_v4sa.v
nano/unicell_gate_core.py

Tang Nano 20K

2. Inside one cell

This is the nano cell, drawn from its Verilog. Its ten gates are always there. The setting does not rewire anything: it only chooses which gate's answer comes out. Change A, B or the setting and watch the values move through the wires.

Shown at one bit so you can read it. The real cell does the same thing on every bit of a wider word at once. The pictures here are drawn by this page's own small script from the same ten equations as the Verilog; they are not the VM running.

3. What 7 + 5 looked like

The library adder was given 7 and 5 and stepped one tick at a time. The bars show how many cells were holding a value at each tick. Two values travel, then one, and the answer lands at tick 18 even though the sum itself is trivial: moving data costs time.

Measured on 10 October 2026 with the step simulator on nano/library_std/add.icm.json (27 cells); it settled after 21 ticks. My reading of the graph: the drop from two values to one is where the two inputs became one result. That reading is an interpretation of the counts, not something the simulator reports.

4. How to run it

  1. Get the files. 
    git clone https://github.com/alh-Imago/Imago-Unicell.git
cd Imago-Unicell
  2. Check what you have. It needs Python 3.12 or newer, it tells you what is missing, and it changes nothing. 
    python3 quickstart.py
  3. Open the composer in your browser. 
    python3 quickstart.py --composer

Status, 10 October 2026: steps 1 and 2 were run and work. Step 3 has not been tried in a browser yet, and the tool does not appear to need anything beyond Python and numpy, but that is not tested on a clean machine.
