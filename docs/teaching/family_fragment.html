The nano cell from the Tour is one member of a family. There are fourteen kinds of flex cell in the repository; this page gives each one a sentence and a link. Every cell will get its own page later, with a live picture like the nano's.

1. What every flex cell shares

Whatever a cell computes, they all hand data on the same way. A cell that has a result holds it, raising a valid signal, until the next cell takes it and answers with an ack. A global freeze stops everything where it stands. Each cell also has a width setting (18 bits on the Tang Nano 20K board). Try the freeze below, or block the sink to see an item wait.

A simplified picture: it shows the idea (hold until taken, pass on only when the next cell is free, one item per two steps through each cell), not the exact signals of any one cell.

2. The cells

Logic and flow

nano

Ten NOR gates and a setting that picks which gate's answer comes out. The cell from the Tour.

held A + flowing B → one result

nano_cell_v4sa.v

Logic and flow

branch

Compares two values and decides lower, equal or higher. What it emits for that outcome is chosen when it is set up. Either input can be a fixed value or a live stream.

two inputs → a three-way decision

branch_cell_v4sa.v

Logic and flow

merge

Where two paths join. Pass only A, pass only B, take whichever arrives (taking turns), or wait for both and combine them with OR.

two paths → one

merge_cell_v4sa.v

Logic and flow

priority

Up to four inputs compete for one output. Strict ranking, weighted turns, or a fixed repeating order. A loser keeps its item and waits.

up to four inputs → one

priority_cell_v4sa.v

Logic and flow

router

One input out to up to two places. Which outputs are switched on is set in advance, never decided while it runs.

one input → up to two outputs

router_cell_v4sa.v

Arithmetic

adder

Adds two values, or subtracts. The carry can come out on a second port.

A, B → sum

adder_cell_v4sa.v

Arithmetic

mul

Multiplies two values. One version is built from ordinary logic, another uses the chip's multiplier blocks. The top half of the product can come out on a second port.

A, B → product

mul_cell_v4sa.v
mul_cell_v4sa_dsp.v

Arithmetic

compare

Says whether a value is at least a threshold (signed), answering 1 or 0.

value → 1 or 0

compare_cell_v4sa.v

Arithmetic

accumulator

A running count that goes up or down when it receives an up pulse or a down pulse.

up / down pulses → count

accumulator_cell_v4sa.v

Arithmetic

shift stage

Slides all the bits left or right by an amount fixed when the design is built. Chain several for a bigger shift.

value → shifted value

shift_stage_v4sa.v

Arithmetic

mask

Cuts out chosen groups of bits by setting them to zero. An 8-bit mask says which groups.

value → value with groups cleared

mask_cell_v4sa.v

Memory and sequence

ram

Holds a word. In fixed mode it is a constant that is always there. In flowing mode it holds a value until the next cell takes it.

word in → word out

ram_cell_v4sa.v

Memory and sequence

latch

Remembers one bit. Set it, clear it, or toggle it.

set / clear / toggle → one bit

latch_cell_v4sa.v

Memory and sequence

sequencer

Holds up to four small stored values (8 bits each) and moves on to the next one each time it gets an advance pulse.

advance pulse → next stored value

sequencer_cell_v4sa.v

The full story of how each cell was designed, with the measured costs, is in sub/README.md. There is also an adder_chain_v4sa.v in the same folder, which strings adders together; it is a helper, not a separate kind of cell.
