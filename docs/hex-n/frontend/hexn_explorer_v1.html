Hex-N Explorer

Train a counted-detector bank in your browser with the same rules as the chip, see what it learns, test it against noise, and export the training set and trained bank for the Tang Nano 20K board. This page follows the counting rules in the design document; the board and the Python model remain the reference.

1. Choose a data set

Each class is one pattern of on/off wires. Training uses noisy copies of it, as the chip does. Example sets load directly; your own files go in below.

Use your own data

Labelled patterns

One pattern per line: a label, then the wires as 0 and 1 (separator may be a space, comma, colon or tab). Lines starting with # are ignored. Train and test lines can be marked with the words train or test at the start.

Make patterns from numbers (CSV)

Rows of numbers with one label column. Each number column becomes one or more wires.

4. What each detector learned

Amber wires add to the detector when on, blue wires subtract, grey wires are ignored. The threshold is the forward total a sample must reach to make the detector fire.

5. Try a pattern

Switch wires on and off. The detector that fires for the most clocks wins; a tie or silence counts as no answer, as on the chip.

6. What if

Each line changes one setting and keeps the rest. Accuracy is the average of five training runs at the chosen test noise. The outlined value is your current setting.

Weight cutoff and threshold bias are experiments. The chip fixes the cutoff at half the samples per class and sets thresholds itself.

7. Memory: save, recall and what to keep

The memory block holds 8 saved patterns. A cue is watched for a few windows, then recalled: the best slot, how well it fits on the wires actually seen, and which wires deviate. With more objects than slots, a write rule decides what to store and what to forget. Pick a rule below, or start from one of the four tested on the board and in simulation.

Slots at the end of run 1 (your rule)

8. Leak setting for a cell

A leaky cell lets its running total drain a little each window, so recent input counts more than old: new level = level − (level shifted right by s). Choose s to see how fast a held level fades when the input stops. This is the board's exact arithmetic; it does not model the input.

9. Export for the board

Copy the text into a file. The training script holds the exact training and test samples for this page's settings. The bank holds the trained weights as the board's positive and negative wire masks.
