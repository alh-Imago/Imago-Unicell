The layers

Each event passes through them in this order. Layer 3 is not built yet.

Event timeline

One row per key press. The prediction was made before the key arrived; the verdict compares it with what came. The goal read is the key the reward values favour next.

Stored sequences

At the end of the run. A sequence is the last few keys and the key that came next; seen counts it, contradicted counts the times its context was followed by something else, value is what the rewards say about it (bar: red below zero, green above; full scale is a reward of +1).

Layer 3

Layer 3 will line up the latest stable key of each of the three sensor channels at one moment and combine them into an inference, with a deeper memory path. It is not built, so nothing here comes from it. The light, pot and thermistor channels of these runs were quiet, so only the remote's keys are shown.

What this view does not show

The keys are the real presses decoded from the recordings, with their real frame counts; no frame damage is added here. The store is the Python model that the RTL is checked against, run in simulation. Nothing has been built for the card. The reward is a rule (the desired goal key), not a measured teacher.
