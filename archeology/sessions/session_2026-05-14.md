### 5. Address space decision (32-bit final)
- All buses stay 32-bit. 64-bit bus / EXTENDED scope: RETIRED.
- Local cell space: 0x00000000 to 0xEFFFFFFF (~3.76B addresses)
- Shore index zone: 0xF0000000 to 0xFFFFFFFF (~268M indexes)
- Top nibble = 0xF → Shore index, NOT a physical address
- Shore table resolves index → {card_id, local_addr, pond_id}
- Indexes are stable logical identifiers — physical destination can change
- Cell writing to 0xFxxxxxxx is transparent: fabric intercepts, Shore resolves
- Enables: migration transparency, named services, capability tokens, cross-card

### 6. Cell command latch simplification (MOST IMPORTANT)
The key insight: config-time and runtime were conflated. Separated cleanly:

- **Command latch** — what the cell *is* (topology + auth, 32 bits fixed)
- **Port latches** — where it *listens and speaks* (addresses, port-local)
- **Command bus** — what it's *told to do right now* (runtime behaviour)
- **Data bus** — what it *computes on* (values)

Command latch reduced to 32 bits:
```
bits  0-10:  NOR topology (11b)
bits 11-21:  auth_mask    (11b) — write-once, hidden
bit   22:    start_flag   ( 1b)
bits 23-31:  reserved     ( 9b) — expansion headroom
```

Port addresses (input_address, output_address) are now local to each port,
set by CMD_SET_INPUT_ADDR / CMD_SET_OUTPUT_ADDR — not stored in command latch.
GS_ mode flags moved to runtime commands on cmd_bus codes 10-15.

## Late addition — PCIe + Standalone backplane strategy

### Two deployment tracks decided

**Track 1: PCIe card (first)**
- Plug into existing x86/ARM host — lowest barrier to entry
- Host OS sees it as an accelerator card
- COMPANION runs on host side, talks to card via PCIe
- Conceptually the same as fpga_bridge.py over UART — PCIe is just faster
- Gets early adopters in without committing to new hardware
- Kintex-7 has PCIe hard IP — confirm exact variant when board arrives

**Track 2: Standalone mainboard/backplane (later)**
- Natural evolution once architecture proven on PCIe
- Card is already self-contained (BIOS-Plus, Ward, Shore, COMPANION)
- Mainboard adds: power, backplane interconnect, SATA, USB, display
- Multiple cards interconnected via backplane

### Why the architecture handles both cleanly
Shore index zone (0xF0000000+) works for both tracks:
- PCIe: host CPU gets a well-known Shore index (e.g. entry 1 = host COMPANION)
- Backplane: other cards get Shore indexes
- Cell programs don't change between deployment models
- Shore table entries point to different physical destinations — transparent

### PCIe bring-up notes (for when Kintex-7 arrives)
- Test PCIe enumeration FIRST — before cell fabric is sitting on top
- Xilinx provide a basic endpoint example design — use as starting point
- DMA preferred over MMIO for bulk data transfer
- BAR-mapped interface replaces UART bridge conceptually
- Good parallel workstream alongside Verilog security hardening
- Easier to debug PCIe in isolation than combined with everything else

Tag: PCIe bring-up = first task on Kintex-7 arrival.

## Late addition — ECC field correction

### The correction
Earlier notes incorrectly described a 39-bit bus packet (32 data + 7 ECC
on bits 32-38). This was wrong. The bus is 32 bits, full stop.
All references to "bits 32-38" and "39-bit packet" are retired.

### The correct model
ECC lives on the command bus, bits 22-31 (already allocated):

```
bits 22-28:  sequence count (7 bits) — packet order + local buffer placement
bits 29-31:  identifier     (3 bits) — source/type tag
bits 22-31:  together = 10-bit soft ECC (XOR check)
```

Pre-Hamming: XOR(received[31:22], expected[9:0]) == 0
When Hamming ECC implemented: same bits become syndrome, same XOR cell.
No architectural rework. No bus widening. Data bus stays 32 bits.

Command bus is now fully and correctly allocated — 32 bits, nothing phantom.

## Late addition — Final 32-bit command latch

### The insight
9 spare bits in the command latch put to good use. One word, complete
cell identity. Load it, the cell is fully defined and live.

### Final 32-bit map
```
bits  0-10:  NOR topology  (11b)
bits 11-21:  auth_mask     (11b) — hidden, write-once
bit   22:    start_flag    ( 1b)
bits 23-24:  type          ( 2b) — NUMERIC/SIGNED/ALPHA/DATETIME
bits 25-26:  cell variant  ( 2b) — standard/edge/latch/reserved
bit   27:    priority      ( 1b) — persistent high-priority flag
bit   28:    trace         ( 1b) — persistent Ward trace
bit   29:    breakpoint    ( 1b) — persistent Ward breakpoint
bits 30-31:  reserved      ( 2b) — hard reserved, do not assign
```

### Why it matters
- CMD_RECONFIGURE = 2 words total (auth_mask at boot + this word)
- Ward, bridge, scheduler all read from one place in one cycle
- Type field direct from cell — no PTT lookup at bridge
- Trace/breakpoint persist across reconfigs — debug sessions survive
- ICM files very compact: one config word + address pair per cell
- This is how the thing really runs

## Late addition — Topology encoding rejected + cmd_bus codes 10-15 confirmed

### Topology encoding: hard no
Considered squeezing NOR topology from 11 bits to 3-4 bits via encoding.
Rejected — not a style preference, a correctness risk:

Cell internals are combinatorial and untimed. NOR tree runs in zero cycles.
A decode stage between command latch and gate tree adds combinatorial delay
to an untimed path. On ASIC this causes timing violations. On a dense array
it causes propagation skew that corrupts results **silently** — no error
signal, wrong answers that look plausible.

The single-cycle guarantee is load-bearing for the entire architecture.
11-bit direct topology map is final. Do not revisit.

### cmd_bus codes 10-15: runtime GS_ flags confirmed
Priority, trace, breakpoint, type, variant moved to command latch (config).
GS_LATCH, GS_SYNC_WAIT, GS_LOOP_BACK, GS_BROADCAST, GS_INVERT_OUT
stay as runtime commands on cmd_bus codes 10-15 — cheap on shared bus,
safe outside the untimed cell internals.

## Late addition — Cell type field + SYNC_WAIT simplification

### Cell type (bits 25-26) revised
"Cell variant" renamed "cell type" with full posedge/negedge encoding:
  00 = standard, 01 = latch, 10 = posedge, 11 = negedge
2-bit decode at RECONFIGURE on static value — safe, not on data path.
Future: three Verilog variants collapse to one parameterised module.

### SYNC_WAIT — no second address
SYNC_WAIT cell counts arrivals at its OWN input_address:
  Arrival 1 → holds, Arrival 2 → fires
Sequence count on cmd_bus bits 22-28 maintains alignment.
No input_b_address, no pass-through cells, no Word 4 in RECONFIGURE.
CMD_RECONFIGURE stays at 2 words. Cleaner, simpler, less silicon.
