### 4. Preload model architecture

Analysed and documented the three-tier preload model:

**Case 1 — Static (NOT, constants)**
→ Solved. `GS_NOT_B (0x002)` replaces `GS_NOT (0x001)`.
  NOT cell now inverts B directly on first arrival. No init=, no CMD_PRELOAD.
  Critical find: GS_NOT = NOT(A) was architecturally wrong — always gave 0
  with a_data=0xFFFFFFFF. Only worked because Python sim bypassed cell execution.

**Case 2 — Partial dynamic (AND/OR/XOR)**
→ Design done. Ordered injection: inject A first (stores), then inject B (fires).
  No PreloadTile needed. Pending implementation.

**Case 3 — Full dynamic (KS adder, prefix trees)**
→ Architecture documented in PRELOAD_MODEL.md.
  Requires PreloadTile — a second region that computes prefix carries
  and writes them to shared bus addresses as natural first arrivals.
  ComputeTile picks them up as a_data, B trigger fires computation.
  ~480 extra cells for INT32_ADD. No CMD_PRELOAD needed.

`docs/PRELOAD_MODEL.md` created — full architecture, three cases,
ICM v3 format sketch, build plan, API design.

### 5. GS_NOT_B fix (Case 1 completion)

The `init=0xFFFFFFFF` approach was wrong at the cell level. Correct fix:
- `GS_NOT (0x001) = NOT(A)` — was used for NOT cells (wrong)
- `GS_NOT_B (0x002) = NOT(B)` — inverts the trigger input directly (correct)
