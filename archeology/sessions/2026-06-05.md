## Lessons from hardware testing

**iCEBreaker constraints (restate clearly):**
- 4 cells maximum — not 1,040 as I incorrectly stated
- 16-bit data bus — cmd_data[31:16]=addr, cmd_data[15:0]=data
- Protocol is 9-byte frame: 0x01 + cmd_bus(4BE) + cmd_data(4BE)
- Reference for all tests: fpga/bringup_v23.py

**First test was wrong:** wrote a 34-cell test for a 4-cell device.
**Second test had wrong opcodes:** CMD_BOOT_COMMIT=0x09 (correct: 0x07).
**Third test had wrong response parsing:** full 32-bit result included
address artefact in high word — mask to 0xFFFF for actual data.

All three errors came from not reading the existing working code first.
Correct approach: read bringup_v23.py before writing any FPGA test.
