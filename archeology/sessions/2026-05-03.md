## test_helpers.py — Chain Latency Formula

Key discovery: chain_latency(n) = n+1, NOT n*2.

The latch model pipelines more efficiently than expected:
- Phase 1 (drain output latches → bus) and Phase 2 (deliver → input latches)
  happen in the SAME tick
- Each downstream cell receives input the same tick its upstream cell drives the bus
- So each cell adds exactly 1 tick of latency to a chain

  n=1: 2 ticks  (load + fire)
  n=2: 3 ticks  (load + fire + fire)
  n=4: 5 ticks  (load + fire*4)

CELL_LATENCY = 2 (for a single cell)
chain_latency(n) = n + 1
