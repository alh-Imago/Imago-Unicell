## What was done

### 1. Command bus — v2.3 unified 32-bit word

**`fpga/verilog/unicell.v`** — major update:
- `cmd_bus` widened from 8-bit to 32-bit unified word
- New field layout: `opcode[7:0]`, `gate_enable[8]`, `gate_set[16:9]`,
  `preload_sel[18:17]`, `shift_in/out[20:19]`, `auth_token[28:21]`
- `CMD_BOOT_COMMIT` (0x07) added — single transaction sets logical addr
  + auth_mask + group_tag → RUN state (replaces old 4-packet boot sequence)
- `preload_sel` — transient modifier: loads 0x00000000 or 0xFFFFFFFF into
  a_data + sets a_arrived. Replaces CMD_PRELOAD + CMD_PRELOAD_HI two-step.
- `shift_in/out` — nibble-aligned barrel shift in/out of gate tree.
  Pure combinational, zero cells for nibble-aligned shifts.
- Two states: BOOT (physical CELL_ID) → RUN (logical address, permanent)
- Compiles clean with iverilog -g2012.

**`fpga/verilog/unicell_array.v`** — cmd_bus widened to 32-bit.

**`fpga/verilog/uart_bridge.v`** — v1.5 → v2.3:
- UART_INJECT frame: 8 bytes → 9 bytes
- `cpu_cmd[7:0]` + `cpu_addr[15:0]` → `cpu_bus[31:0]`
- Frame decoder updated: bytes 1-4 = cmd_bus, bytes 5-8 = cmd_data

**`fpga/verilog/top_icebreaker.v`** — v2.0 → v2.3:
- `cpu_bus[31:0]` wiring
- `cmd_valid_w` checks `cpu_bus[7:0]` (opcode field)

### 2. Gate state bit corrections

**`gate_states.py`** — two critical bugs fixed:
- `GS_LATCH_IN` was `0x02000000` (bit 25, wrong) → `0x04000000` (bit 26)
- `LOOP_MODE` was `0` (silent bug) → `GS_LOOP_BACK = 0x80000000`
- `GS_INVERT_OUT_BIT` added at bit 25 (separate from latch_in)
- `GS_FALL_EDGE` alias added: `GS_EDGE_MODE | GS_INVERT_OUT_BIT`
- Auth_mask field corrected: 11-bit → 8-bit (bits 18:11)

**`unicell.py`** — Python VM:
- `latch_in` now reads bit 26, `invert_out` reads bit 25 (separate)
- Was reading both from old 2-bit `cell_type` field (incorrect)
- gate_states imports added

### 3. Python interface layer

**`command_interface.py`** — full rewrite for v2.3:
- `build_cmd_bus()` produces 32-bit unified word
- `decode_cmd_bus()` unpacks all fields
- `build_boot_commit()` — one-transaction boot helper
- `CMD_BOOT_COMMIT` dispatch in `_issue()`
- `preload_sel` applied as transient after opcode
- Full docstring with boot/run protocol

**`fpga/fpga_bridge.py`** — v2.3 + v2.2 legacy:

- `boot_cell()` uses CMD_BOOT_COMMIT in v2.3 mode (2 transactions vs 4)
- `make_cmd()` / `build_config_word()` kept as backward-compat shims
